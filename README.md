# sledopyt-site

Опубликованная версия сайта проекта «Следопыт» — учебного проекта по
сопровождению семьи в освоении видеоувеличителя.

**Репозиторий открытый намеренно.** Здесь лежит только то, что и так видно
любому посетителю сайта: готовые файлы страницы. Исходники, документация
и черновики — в отдельном закрытом репозитории.

Открытость нужна, чтобы сервер мог забирать обновления без ключей и паролей:
входящие соединения к нему фильтруются, поэтому он сам ходит за свежей версией.

## Что внутри

| Путь | Что это |
|---|---|
| `site/` | файлы сайта, их раздаёт nginx |
| `setup.sh` | разовая настройка сервера |

## Как устроена публикация

```
push сюда  →  сервер забирает раз в минуту  →  сайт обновился
```

Сервер недоступен снаружи по обычным портам, поэтому наружу он смотрит через
обратный туннель Cloudflare: сам дозванивается и держит канал. Заблокированный
IP-адрес в схеме не участвует.

## Разовая настройка сервера

От root:

```
cd /opt
git clone https://github.com/catis-test/sledopyt-site.git
bash sledopyt-site/setup.sh
```

Скрипт настроит nginx на раздачу `site/`, оформит туннель системной службой
и заведёт задание, которое раз в минуту забирает свежую версию. В конце
напечатает адрес сайта.

Запускать повторно безопасно — всё перезаписывается заново.

## Полезные команды

```
systemctl status sledopyt-tunnel        состояние туннеля
grep trycloudflare /var/log/cloudflared.log    текущий адрес
systemctl restart sledopyt-tunnel       перезапустить (адрес сменится)
```

Адрес случайный и меняется при перезапуске туннеля — постоянный требует
своего домена, привязанного к Cloudflare.

## setup-bot.sh

Разовая настройка сервера под бота «Следопыта». Запускать в VNC-консоли:

```
bash /opt/sledopyt-site/setup-bot.sh <пароль>
```

Секретов в файле нет — только пути и адрес закрытого репозитория.
